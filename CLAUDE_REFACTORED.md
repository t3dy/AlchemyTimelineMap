# Claude Code Instructions — ALCHEMYTIMELINEMAP

**An interactive timeline and map of alchemy and chemistry, 500 events across Late Antiquity through the early modern period. Coverage: Europe, North Africa, Middle East.**

---

## Non-Negotiable Invariants

1. **Actor/Analyst distinction** (Hanegraaff framework): Distinguish between terms used by historical practitioners and modern retrospective categories.
2. **Medieval continuity**: No "dark age" gap. Alchemy is a continuous tradition from Late Antiquity through Arabic, Byzantine, and Latin medieval periods into the Renaissance.
3. **Operational chemistry**: Chemical operations (distillation, sublimation, etc.) were real, reproducible, material practices. Separate them from transmutation theory.
4. **Named-source scholarship**: Every claim traces to a cited scholar (Newman, Pereira, Hanegraaff, etc.). No vague attributions.
5. **No esoteric framing**: This is a scholarly reference portal, not a guide to practice or endorsement of transmutation.

## Core Architecture (30 seconds)

```
Seed JSON (data/) 
  ↓ [Python scripts]
SQLite (db/alchemy_timeline.db) [source of truth]
  ↓ [Agent enrichment via staging/]
Static HTML (site/) [regenerated by build_site.py]
  ↓ [Deploy to GitHub Pages]
```

**Key principle:** SQLite is the database. Python scripts are idempotent. No frameworks. All agent output validated before DB insertion.

## The 8 Tables (Schema Summary)

- **timeline_events**: 500 dated, geotagged events (100–250 words each)
- **persons**: Alchemists, chemists, scholars (1,200–2,200 words each)
- **texts**: Treatises, commentaries, scholarship (1,000–1,800 words each)
- **concepts**: Operations, theories (1,500–2,500 words each, with ACTOR_TERM/ANALYST_TERM distinction)
- **locations**: Cities/regions with lat/lon coordinates
- **person_event_refs, text_event_refs, concept_event_refs**: Linking tables

For full schema, see `docs/ONTOLOGY.md`.
